Common C++ functions & STL

A practical reminder of frequently used standard-library algorithms, containers, and string utilities. Include the appropriate header, or use <bits/stdc++.h> in GCC-based competitive programming environments.

Algorithms — <algorithm>

Sorting & rearranging

sort(v.begin(), v.end())

Sort ascending; add greater<int>() for descending.

stable_sort(v.begin(), v.end())

Sort while preserving the order of equivalent elements.

reverse(v.begin(), v.end())

Reverse a range.

rotate(v.begin(), v.begin()+k, v.end())

Rotate a range.

next_permutation(v.begin(), v.end())

Generate the next lexicographical permutation.

prev_permutation(v.begin(), v.end())

Generate the previous permutation.

Searching & checking

find(first, last, x)

Return iterator to first matching value, or last.

binary_search(first, last, x)

Check whether x exists in a sorted range.

lower_bound(first, last, x)

First position with value ≥ x (sorted range).

upper_bound(first, last, x)

First position with value > x (sorted range).

count(first, last, x)

Count occurrences.

all_of / any_of / none_of(first,last,pred)

Test a predicate across a range.

Min, max & partition

min(a, b), max(a, b)

Smaller or larger of two values.

min_element(first, last)

Iterator to the minimum element.

max_element(first, last)

Iterator to the maximum element.

minmax_element(first, last)

Pair of iterators to min and max.

unique(first, last)

Move consecutive duplicates to the end; usually combine with erase.

partition(first, last, pred)

Group elements by a predicate.

Other useful algorithms

fill(first, last, value)

Fill a range with one value.

iota(first, last, start)

Fill with increasing values (header <numeric>).

copy / copy_if / transform

Copy or transform elements into another range.

remove(first, last, x)

Remove-value idiom; combine with erase.

nth_element(first, nth, last)

Place the element that would be at nth in sorted order.

clamp(x, low, high)

Restrict a value to an interval (C++17).

Numeric — <numeric> and <cmath>

Numeric algorithms

accumulate(first,last,0LL)

Sum values; use 0LL to accumulate in long long.

partial_sum(first,last,out)

Build prefix sums into an output range.

adjacent_difference(first,last,out)

Differences between adjacent values.

gcd(a,b), lcm(a,b)

Greatest common divisor / least common multiple (C++17).

iota(first,last,0)

Fill sequential values.

Math functions

abs(x), llabs(x)

Absolute value.

sqrt(x), cbrt(x)

Square root / cube root.

pow(a,b)

Power; returns floating-point.

ceil(x), floor(x), round(x)

Rounding operations.

log(x), log2(x), log10(x)

Logarithms.

Strings — <string>

Read & modify

s.size(), s.length(), s.empty()

Length and emptiness.

s.substr(pos, len)

Extract substring.

s.find(t), s.rfind(t)

Find first / last occurrence; compare with string::npos.

s.erase(pos, len), s.insert(pos, t)

Erase or insert characters.

s.push_back(c), s.pop_back()

Add or remove final character.

s += t, s.append(t)

Append text.

Character & conversion

tolower(c), toupper(c)

Convert a character; cast through unsigned char for arbitrary byte values.

isalpha(c), isdigit(c), isalnum(c)

Character classification.

isspace(c), islower(c), isupper(c)

Whitespace / letter checks.

stoi(s), stoll(s), stod(s)

Convert string to number.

to_string(x)

Convert number to string.

stringstream ss(s)

Parse formatted data from a string (<sstream>).

Containers — common operations

Sequence containers

vector<T> v

push_back, emplace_back, pop_back, front, back, at, [], size, empty, clear, resize, reserve, begin, end.

array<T,N> a

Fixed-size array; size, fill, front, back, at, [], begin, end.

deque<T> d

push_front, push_back, pop_front, pop_back, front, back, [], size.

list<T> l

push_front/back, pop_front/back, insert, erase, remove, sort, reverse, splice.

string s

Character sequence with string-specific operations above.

Adapters

stack<T> st

push, emplace, pop, top, size, empty.

queue<T> q

push, emplace, pop, front, back, size, empty.

priority_queue<T> pq

push, emplace, pop, top, size, empty. Default is max-heap.

priority_queue<T, vector<T>, greater<T>> pq

Min-heap.

Ordered associative

set<T> / multiset<T>

insert, emplace, erase, find, count, lower_bound, upper_bound, size, empty. Sorted keys; set unique, multiset allows duplicates.

map<K,V> / multimap<K,V>

[], at (map), insert, emplace, erase, find, count, lower_bound, upper_bound. Sorted keys; multimap allows duplicate keys.

Unordered associative

unordered_set / unordered_multiset

insert, emplace, erase, find, count, reserve, rehash, size. Average O(1); no sorted order.

unordered_map / unordered_multimap

[], at (unordered_map), insert, emplace, erase, find, count, reserve, rehash. Average O(1); multimap allows duplicate keys.

Utilities & common patterns

Pairs, tuples & bits

pair<A,B> p; make_pair(a,b)

Access p.first and p.second.

tuple<A,B,C> t

make_tuple, get<0>(t), tie(a,b,c).

bitset<N> b

count, test, set, reset, flip, any, none, all.

__builtin_popcount(x)

Count set bits in unsigned int; use __builtin_popcountll for unsigned long long (GCC/Clang).

numeric_limits<T>::max()

Largest representable value of type T.

Iterators & lambdas

begin(c), end(c), rbegin(c), rend(c)

Forward and reverse iterators.

distance(first,last)

Distance between iterators.

next(it), prev(it)

Move an iterator forward / backward.

auto cmp = [](int a,int b){ return a>b; };

Lambda comparator example for descending order.

sort(v.begin(),v.end(),cmp)

Sort with a custom comparator.

Tip: know the complexity and iterator requirements of each operation. For example, lower_bound on a vector is O(log n), while calling it on a set is unnecessary because set already provides its own lower_bound member function.
